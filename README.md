# RevivePayAI – AI Revenue Recovery System

## Overview
RevivePayAI is an AI-powered revenue recovery system developed using Python and Django. It helps identify failed transactions and monitor potential revenue loss, supporting businesses in understanding and managing payment failures.

## Features
- Monitors failed transactions.
- Identifies revenue at risk.
- Helps track payment failures.
- Provides a web-based interface.
- Supports revenue recovery monitoring.

## Technologies Used
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQL / SQLite
- **Development Tools:** VS Code, Git, GitHub

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/ramavathtejaswini5386-hash/RevivePayAI.git
   ```

2. Navigate to the project folder:
   ```bash
   cd RevivePayAI
   ```

3. Install dependencies:
   ```bash
   pip install django
   ```

4. Run database migrations:
   ```bash
   python manage.py migrate
   ```

5. Start the development server:
   ```bash
   python manage.py runserver
   ```

6. Open the application in your browser:
   ```text
   http://127.0.0.1:8000/
   ```
